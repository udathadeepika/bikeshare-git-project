# Bikeshare Data Explorer

## Description
A Python program that explores bike share data for US cities. The user picks a city, month and day, and the program prints statistics on travel times, popular stations and trips, trip duration, and rider information.

## Requirements
- Python 3
- pandas

## Usage
Run `python bikeshare.py` and answer the prompts.

## Files
- `bikeshare.py` - main program
- `new_york_city.csv` - data file (not uploaded, see `.gitignore`)
- `.gitignore` - excludes csv files from Git
